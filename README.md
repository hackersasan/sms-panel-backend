###  About
A simple and efficient backend for an **SMS Marketplace**, built with **Node.js** and **Express**. This project stores data in **JSON files** and uses various middlewares for file handling and security.

###  Features
- JSON-based storage (no database required)
- Built with **Express.js**
- File upload support using **Multer**
- Password hashing using **Crypto** module
- Path management using **Path** module
- Runs on **port 8080**

###  Requirements
- Node.js (v14 or higher)
- npm

###  Installation & Setup

```bash
# Clone the repository
git clone https://github.com/sms-panel-backend/sms-panel-backend.git

# Navigate to project folder
cd sms-marketplace-backend

# Install dependencies
npm install express multer
```
